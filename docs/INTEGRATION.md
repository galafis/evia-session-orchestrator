# Integration · Integração

## English

Use a practitioner-reviewed activity plan from Inclusive Session Studio to author explicit events. Review stop and withdrawal sequences with adult collaborators using the software alone. Any future device adapter must preserve these event semantics and produce separate physical test evidence.

The public interface is a versioned scenario and report pair. Keep the scenario, report, source label and repository release together. Do not substitute private device messages for this schema or infer compatibility from similar field names. Device integration remains a separately scoped adapter.

## Português

Use um plano de atividades do Inclusive Session Studio, revisado por profissionais, para definir eventos explícitos. Revise as sequências de parada e retirada com colaboradores adultos usando apenas o software. Um futuro adaptador de dispositivo deve preservar a semântica desses eventos e produzir evidências próprias de testes físicos.

A interface pública é um par versionado de cenário e relatório. Mantenha juntos cenário, relatório, rótulo de origem e versão do repositório. Não substitua o esquema por mensagens privadas de dispositivos nem deduza compatibilidade de campos parecidos. A integração com dispositivos permanece um adaptador de escopo separado.
